KEC Student Academic & Continuous Evaluation System

Project Overview

A Java JDBC-based application developed to manage student academic records and continuous evaluation at Kongu Engineering College under Regulation 2024.

Technologies Used

- Java
- JDBC
- MySQL
- Git and GitHub

Features

- Student registration and management
- Course management
- Student enrollment
- Attendance management
- Continuous internal assessment marks entry
- End-semester examination marks management
- Academic result generation

Project Structure

- "MainApp.java" – Main application
- "DBConnection.java" – Database connectivity
- "StudentDAO.java" – Student operations
- "CourseDAO.java" – Course operations
- "EnrollmentDAO.java" – Enrollment operations
- "AttendanceDAO.java" – Attendance operations
- "MarksDAO.java" – Marks management
- "ResultDAO.java" – Result management

Database

MySQL database connected through JDBC.
